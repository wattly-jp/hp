# 記事テーマ一覧

テーマと切り口案のストック。記事化したいものに `- [x]` をつける → まとめてClaude に渡すと一気にdraftを生成する。

**使い方:**
1. 記事化したいテーマの先頭チェックボックスを `- [x]` に変える
2. 「チェックしたやつdraft化して」とClaude に伝える
3. Claude がチェック済みのテーマを全てdraft化 → draft化したthemeは削除

**切り口の原則:**
- 「具体（入口）→ 抽象（本質）」の順。具体と抽象はなるべく遠いところを行き来する
- タイトル自体に「なぜその概念が？」という引っかかりを持たせる
- **電力・電気料金の話に毎回帰結させなくていい。面白い観察・構造が核で、電気はかすりさえすれば十分。「この比喩で電力の何を説明できるか」という逆算はしない**

## 構造・視座系

- [ ] ### 「世界で一番高い山は？」と聞かれて、答えは一つではない
> 測定基準を変えると、順位が全部入れ替わる。基底面からならマウナ・ケア、地球の中心からならチンボラソ
- 海面からの高さ、基底面からの高さ、地球の中心からの距離——「一番高い」の定義が3つあり、答えが3つ違う
- 「一番安い電力会社」も基本料金で見るか、従量料金で見るか、年間総額で見るかで順位が入れ替わる構造と相似

## 社会・構造系

- [ ] ### パリの下水道は、パリの道路より先に設計された
> インフラは「見える部分」より「見えない部分」の方が先に決まる。都市設計と制度設計の共通構造
- オスマンの都市改造：美しい大通りより先に下水と水道を引いた。見えるものは後から変えられるが、見えないものは最初に決めないと取り返しがつかない
- 電力自由化の「送配電分離」がなぜ最も難しい改革だったのか。表面の料金体系より、裏の配電網設計が全体を規定する

- [ ] ### 「座席指定」が導入された瞬間、自由席の価値が変わった
> 選択肢が増えると既存の選択肢の意味が変質する。「選べる」こと自体が構造を変える
- 新幹線「のぞみ」の全車指定席化。自由席がなくなると「安く座れる」オプションが消え、指定席の「安心感」が相対的に下がる
- 電力自由化で「選べるようになった」こと自体が、旧来の規制料金の意味を変えた。選ばないことが「判断」になった

- [ ] ### 橋は「渡るため」に作られたが、「渡らないため」にも使われている
> インフラの当初目的と実際の機能は往々にして乖離する
- 中世ヨーロッパの橋は関所として通行税を徴収する装置だった。「繋ぐ」ために作ったものが「遮断する」ために使われる逆転
- 送配電網は電気を届けるインフラだが、同時に「新規参入の障壁」としても機能している。接続コストとルールが新電力の参入を制約する

## 技術・しくみ系

- [ ] ### 時計職人は、完成した時計を壊してから出荷する
> 品質検査の本質——「正常に動く」ことを確認するには、一度「壊れる条件」を試す必要がある
- スイスの高級時計メーカーは完成品を極端な温度・衝撃・磁場に晒してから出荷する。「壊れなかった」ことが品質の証明
- ソフトウェアのカオスエンジニアリング（Netflixの"Chaos Monkey"）、電力系統の「ストレステスト」——安定を証明するために不安定を意図的に作る

- [ ] ### 楽器のチューニングは「正しい音」に合わせているのではない
> 平均律と純正律——「完璧な音程」は物理的に存在するが、実用上は「ちょうどいい妥協」を使っている
- ピアノの調律は全ての音程をわずかにズラすことで、どの調でも「まあまあ合っている」状態を作る。完璧な和音を犠牲にして汎用性を取る
- 電力系統の周波数維持（50Hz/60Hz）も「完璧な一定」ではなく「許容範囲内の変動」。完璧を目指すと系統全体が脆くなる

- [ ] ### コンクリートは「固まる」のではなく「水と反応し続けている」
> 日常的に見ている素材が、想像と全く異なるプロセスで成立している例
- コンクリートの硬化は乾燥ではなく水和反応。水がないと固まらない（散水養生する理由）。打設後も数十年間反応が続いている
- 電力系統も「安定している」のではなく「常に調整し続けている」。需給バランスは秒単位で変動し、発電機が常に出力を微調整している

## 暮らし・行動系

- [ ] ### 引っ越しの翌日に届くDMは、なぜ前の住人宛なのか
> データの「粘着性」——情報は更新されるが、古い情報が消えるのには時間がかかる
- 住所変更後も届き続けるDM、退会したはずのメルマガ、更新されない地図アプリ。データは「生まれる」のは一瞬だが「死ぬ」のには年単位かかる
- 電力契約の「前の住人の契約」をそのまま引き継いでしまう構造


- [ ] ### 冷凍食品の「解凍」は、料理を逆再生しているのではない
> 「元に戻す」ように見えるプロセスが、実は不可逆な変化を伴っている
- 冷凍→解凍で細胞壁が壊れ、食感が変わる。「冷凍前の状態に戻る」のではなく「冷凍・解凍を経た新しい状態」になる
- 電力自由化後に「規制料金に戻る」選択肢も、実は「自由化前と同じ」ではない。戻れるように見えて、構造が変わっている

- [ ] ### 満員電車で「押されている」のは、実は「引かれている」
> 群衆の物理学——押し合っているように感じるが、実際には空いた隙間に吸い込まれている
- 群衆力学：人混みの動きは流体力学で記述できる。「押す力」よりも「密度勾配による吸引」が群衆事故の主因
- 電力需要のピーク時に「みんなが使いすぎている」のではなく、構造的に需要が集中するタイミングが存在する

## 優先順位の考え方

1. **構造・視座系を柱にする**: SNSシェア・被リンク狙い。「Wattlyといえばこの切り口」というブランド形成
2. **社会・構造系は時事性で伸ばす**: 具体的な事件・データと紐づける
3. **暮らし・行動系はロングテール流入の入り口**: 「電気代 下がらない」「節電 意味ない」系の検索
4. **法人系はCV直結**: 検索ボリュームは小さいが高単価アフィリエイトに繋がる
