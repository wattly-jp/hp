# Wattly 事業情報・市場

## 事業概要

- **ステータス**: Phase 0（アフィリエイトメディア構築）
- **戦略**: まずアフィリエイトメディアでドメイン知識 + ドメインパワー + 収益を蓄積 → SaaS展開
- **Casinohubとの違い**: Casinohubは「作るべきSaaSが明確」なので即開発。Wattlyは「何のSaaSを作るかが未定」なのでメディア運営で知見を貯めてから判断。ただしメディア運営中に明確なペインが見つかったらPVに関係なく即動く

## フェーズ

### Phase 0: アフィリエイトメディア運営（現在）
- 電力会社比較・乗り換え系のSEOコンテンツ制作
- アフィリエイト案件の調査・提携
- ドメインパワーの構築
- 目標: 月3万PV / 記事50本 / 6〜9ヶ月

### Phase 1: SaaS方向性の決定（月3〜5万PV到達後）
- 読者のコメント・質問からペインを把握
- メルマガ/LINEで見込み客リスト構築（数百人目標）
- SaaS仮説を1つに絞る

### Phase 2: MVP開発
- Phase 1 で決定した方向性に基づいて設計・開発

## SaaS候補（仮説段階）

- 電力料金シミュレーター（BtoC → メディアに組み込みSaaS化）
- 需要家（法人）向け電力コスト最適化ツール
- 太陽光/蓄電池の見積もり・管理ツール
- EV充電スタンド管理
- 補助金検索・申請支援ツール

### 有力候補: 法人向けEV導入コストシミュレーター（2026-03-12 競合調査済み）
- **空白市場**: 法人がセルフサービスでEV導入のTCOを概算できるWebツールは現時点でゼロ
- 大手（東京ガス Charge Planner、NTT EV Start Biz、REXEV）は全てコンサル型で、セルフサービスツールを提供していない
- **特に空いている領域**: 国＋都道府県＋市区町村の3レイヤー補助金横断検索、社用車フリートのTCOシミュレーション
- **タイミング**: Phase 1（月3〜5万PV到達後）で本格検討

### 登録すべきASP
- **A8.net**: 案件数最多
- **アクセストレード**: エネルギー・インフラ系に強い
- **バリューコマース**: 大手電力の公式案件

- **レントラックス（クローズド）**: 太陽光・蓄電池高単価

## 競合・市場環境

### 競合メディア
- **エネチェンジ**: SEOで主要KWほぼ全て上位。上場企業。正面対決は避ける
- **価格.com**: ドメインパワー圧倒的。避ける
- **個人メディア群**: ロングテール・地域特化で勝負の余地あり

### 既存の電力SaaS（将来の競合/参考）
- エネがえる（太陽光シミュレーション）
- エネチェンジBiz（法人電力比較）
- パネイル（需給管理）
- スイッチビズ（高圧電力見積もり）

### 市場環境
- 電力自由化（2016年〜）で新電力が乱立、消費者は比較ニーズ大
- 電気料金高騰が続き「電気代 節約」の検索ボリューム↑
- 太陽光・蓄電池への関心がシフト（卒FIT需要拡大）
