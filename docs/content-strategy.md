# Wattly コンテンツ戦略・記事執筆

## SEO戦略（2層構造）

エネチェンジ・価格.comが「比較・おすすめ」系を押さえているため、正面衝突は避ける。**視座系（看板記事）と実用系の2層構造**で攻める。

**視座系（看板記事）: 月1〜2本、しっかり書く**
- 「問いを立てる」「前提を疑う」「構造を俯瞰する」切り口
- 例: 「電気代は本当に高いのか？」「電力自由化は誰のためだったのか」
- 競合が書かない領域。AIでも量産できない（視座が必要）
- SNSシェア・被リンクでドメインパワーを育てる

**実用系: 効率的に数を揃える**
- 節約・比較・制度解説などの実用記事
- 視座系で育てたドメインパワー+内部リンクの恩恵でSEO上位を狙う
- アフィリエイト成約はこちらで担う

## 記事戦略（SEO優先度）

### 優先すべき記事テーマ
1. **電気料金の基礎知識系**（料金の仕組み、再エネ賦課金、燃料費調整） — 検索ボリューム大、E-A-T基盤になるクラスター記事群
2. **節約・比較系**（一人暮らしの電力会社選び、電気代を下げる方法） — アフィリエイト導線に直結
3. **法人向け**（法人電力コスト最適化、高圧電力見積もり） — 競合少なく高単価案件に繋がる

### 後回しでいい記事テーマ
- 技術トレンド系（SMR、GX-ETS等）は専門性が高い分ボリュームが小さい

## 記事作成ワークフロー（3ステップ）

**Step 1: 角度ブレスト（必須・執筆前にユーザー確認）**
- テーマに対して構造・切り口・視点を3〜5案出す（読者が「え？」と思うもの）
- 常識・正論・ありきたりな答えは除外
- **ユーザーが選んだ案が確定するまで執筆しない**

**Step 2: 具体 ↔ 抽象の設計**
- **具体（入口）**: 読者が「あるある」と思える場面描写から入る
  - 例:「9月の電気代明細を開いた瞬間、数字が目に飛び込んできた。先月より3,000円高い」
- **抽象（本質）**: 具体のシーンから、より深い構造・問いへ引き上げる
  - 例:「電気代の請求書は、インフラコストの明細ではなく、リスクの分配票だ」
- **具体→抽象の順**: 抽象から入ると読者が離れる。必ず具体から始める

**Step 3: 執筆**
- Step 1-2で方向が決まってから書き始める
- 毎回同じ構成にしない

## ライティング哲学（最重要）

**独創的な切り口・抽象と具体の往復・遠い比喩——これが競合に真似できないWattlyの文体の核心。**

### 切り口の作り方
- **ありきたりな「まとめ記事」「おすすめ記事」は作らない**
- **問いの逆転**: 「電気代を下げるには？」ではなく「電気代が下がらない構造とは何か？」
- **前提を疑う**: 「電力会社は電気を売っている」「節電は正しい」——当たり前の前提を問い直す
- **他分野からの輸入**: 電力の話を金融・行動経済学・農業・都市計画の言葉で語る

### 比喩・比較の作り方（遠い対象を使う）
- **遠い領域から持ってくる**: 電力プラン選び = 変動金利 vs 固定金利、新電力の撤退 = サブプライム崩壊
- **スケールを跨ぐ**: 国家規模（電力網・GX政策）と個人規模（冷蔵庫1台）を同じ文章に共存させる

## フォーマット要件

- **タイトル（H1）**: キーワードを前半に配置、最大32文字
- **見出し階層**: H1 → H2 → H3 を厳守（飛ばさない）
- **リード文**: 読者の課題に共感 → 記事で何がわかるか説明（150〜200字）
- **メタディスクリプション**: 最大120文字
- **スラッグ**: 英語ハイフン区切り（例: `electricity-bill-structure`）
- **文字数**: 3,000〜7,000字

## セルフレビューチェックリスト（記事）

- [ ] タイトル32文字以内、キーワードが前半にあるか
- [ ] H1→H2→H3の階層が守られているか
- [ ] リード文で読者の課題に共感し、記事の内容を予告しているか
- [ ] メタディスクリプションが120文字以内か
- [ ] 断言できないことを断言していないか
- [ ] 具体シーンが最低1つあるか
- [ ] 同テーマの既存記事と表現が被っていないか
- [ ] 内部リンクが適切に設置されているか
- [ ] CTAが記事末尾にあるか
- [ ] アフィリエイト導線が将来差し替え可能な構造になっているか
- [ ] 数値データの出典が確認済みか

## 禁止コンテンツ

- 虚偽・誇張した表現
- 競合サービスの名指し比較・批判（エネチェンジ等の名前を出して「こっちが上」は絶対NG）
- 法的に不正確な記述（電力自由化制度・再エネ賦課金等は正確に）
- 他サイトのコピー・リライト
- 「いかがでしたか」等の定型フレーズ
- 上から目線の「教えてあげる」口調
