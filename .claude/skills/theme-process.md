# テーマ処理スキル

`marketing/article/themes.md` のチェック済みテーマ（`- [x]`）を処理する定期タスク。

## 手順

1. **themes.md を読む** — `- [x]` または `- [X]` のテーマを全て抽出する
2. **チェック済みテーマごとにdraftを作成** — `marketing/article/draft/` にmarkdownファイルとして書き出す。CLAUDE.mdのコンテンツ戦略・ライティング哲学に従う
3. **チェック済みテーマをthemes.mdから削除する**
4. **削除した数と同じ数の新しいテーマを追加する** — 以下の原則に従う:
   - 電力・電気料金の話に毎回帰結させない。面白い観察・構造が核で、電気はかすりさえすれば十分
   - 「この比喩で電力の何を説明できるか」という逆算はしない
   - 抽象と具体はなるべく遠いところを行き来する
   - 比喩・比較もなるべく遠い業界・領域から持ち込む
   - 既存のテーマや公開済み記事とテーマ・切り口が被らないようにする
5. **コミット＆push** — 確認不要で実行する
